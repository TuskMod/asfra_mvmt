
asfra_mvmt is a re-worked version of the step-selection function developed for 

Chalkowski, K., Sack, A., Wittemyer, G. et al. Predicting animal movement metrics across the species range for landscape-scale applications. Mov Ecol (2026). https://doi.org/10.1186/s40462-026-00707-0

This takes a random forests model for sounder movement developed by W. Raymond scaled to weekly sounder movement according to landscapes (instead of daily, as in the paper). The material in this repo DOES NOT generate these models, it is just a way to generate predictions using contiguous US input data. Data is also not included but can be obtained by contacting eric.sodja@usda.net. Some data is publicly available and is listed below (coming soon...)
